# Grug Digital

Website for Grug Digital: websites, TV menu boards, rewards apps and branded games for local Katy shops.

- `index.html` is the full site. It also runs on GitHub Pages: https://gabrielman25.github.io/grugdigital/
- `work/` holds the concept sites, screenshots, pitch-pack pages and PDFs.
- `community/` holds the neighborhood photos and the map (map data © OpenStreetMap contributors; photos from Unsplash).

The Google Sites button (`elyson-digital-google-sites.html`) contains the site's page code and loads these files through jsDelivr:
https://cdn.jsdelivr.net/gh/gabrielman25/grugdigital@main/
